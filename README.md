# team-remaster - конвейер обработки документов

Сервис принимает документы (PDF, DOCX, TXT) и задания на их обработку: извлечение текста,
подсчёт статистики, конвертацию формата и перевод. Каждое задание проходит жизненный цикл,
а результат и история сохраняются.

## Какую проблему решает

Обработку документов часто делают вручную: открыть файл, скопировать текст, посчитать
объём, перевести, сохранить в другом формате. Для десятков файлов это долго и с ошибками.
Сервис даёт единый API: загрузил документ, поставил задание, получил результат и статус.

## Для кого

- Студенты и преподаватели, которым нужно пакетно обработать материалы.
- Разработчики других сервисов, которым нужна обработка документов через API без своей реализации.

## Что входит в систему

- Загрузка документов и проверка формата и размера.
- Задания на обработку (Job) с жизненным циклом: `uploaded → queued → processing → processed / rejected / failed`, отмена — `cancelled`.
- Процессоры за единым контрактом: извлечение текста, статистика, конвертация формата, перевод.
- Внешний сервис перевода (LibreTranslate) через адаптер с timeout и retry.
- REST API с контрактом OpenAPI, идемпотентное создание заданий.
- Хранение метаданных, заданий и истории в БД с миграциями.

## Что не входит

- Пользовательский интерфейс (работа через API и Swagger UI).
- Регистрация и авторизация пользователей.
- Распознавание сканов (OCR).
- Деплой в облако.

## Стек

Python 3.14, FastAPI, SQLAlchemy + Alembic, SQLite -> PostgreSQL, pytest, Docker Compose, GitHub Actions.
